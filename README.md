# BudgetPH – Expense & Budget Tracker

A Progressive Web App (PWA) for tracking expenses, income, and bills in Philippine Peso.

## 🚀 Deploy to Netlify (FREE)

### Option 1: Drag & Drop (Easiest)
1. Go to **https://app.netlify.com**
2. Sign up / Log in (free)
3. Click **"Add new site" → "Deploy manually"**
4. **Drag and drop this entire folder** onto the upload area
5. Wait ~30 seconds → Your app is live! ✅
6. Copy the URL (e.g. `https://amazing-name-123.netlify.app`)

### Option 2: GitHub (recommended for updates)
1. Push this folder to a GitHub repo
2. Connect Netlify to GitHub
3. Auto-deploys on every push

---

## 📱 Install on Your Phone

### Android (Chrome):
1. Open your Netlify URL in Chrome
2. Tap the **3-dot menu** → "Add to Home Screen"
3. Tap "Install" → App icon appears on home screen!

### iPhone (Safari):
1. Open your Netlify URL in **Safari** (must be Safari!)
2. Tap the **Share button** (box with arrow up)
3. Scroll down → Tap **"Add to Home Screen"**
4. Tap "Add" → App icon appears!

## ✨ Features
- 💰 Track income with dates
- 💸 Track expenses by category with dates
- 🧾 Add bills with due dates & recurring options
- ✅ Tick bills as paid (auto-deducted from balance)
- 📅 Calendar view with color-coded dots
- 🔔 Notifications for bills due today
- 📊 Real-time balance calculation
- 🗑️ Clear all data option
- 💾 Data saved locally on your device
- 📴 Works offline after first load
